# Consult Note 사용 가이드

고객과의 상담 내용을 기록하고, 필요한 견적과 서류를 빠르게 찾는 프로그램입니다. 아래 순서대로 사용하면 됩니다.

## 1. 프로그램 시작하기

받은 ZIP 파일의 압축을 풀고 **SalesConsultationTracker.exe**를 실행합니다. 자주 사용한다면 실행 파일의 바로가기를 바탕화면이나 작업 표시줄에 만들어두세요.

프로그램이 열리면 기존 고객을 선택하거나 새 고객을 등록해 상담을 시작합니다.

## 2. 고객 등록하고 찾기

1. **고객 추가**를 누르고 이름과 연락처를 입력합니다.
2. 저장한 고객을 선택합니다.
3. 기존 고객은 상단 검색창에 이름, 전화번호 일부 또는 차량명을 입력해 찾습니다.

자주 확인하는 고객은 이름 옆 **★**로 즐겨찾기에 등록해두면 목록에서 먼저 볼 수 있습니다.

## 3. 상담 내용 기록하기

1. 고객을 선택하고 차량, 계약기간, 주행거리 등 확인된 조건을 양식에 적습니다.
2. 상담 기록 입력칸에 이번 통화 내용을 작성합니다.
3. 통화 결과에 맞게 **상태**를 선택합니다.
4. **저장**을 누릅니다. 단축키는 **Ctrl+Enter**입니다.

저장하면 고객 정보와 양식, 상담 내용이 함께 반영됩니다. 상담 내용이 비어 있으면 양식만 저장하고 빈 상담 기록은 추가하지 않습니다.

상태 입력은 매번 **상담중**이 기본입니다. 부재나 심사 등으로 남기려면 저장 전에 상태를 바꿔주세요. 과거 상담 기록은 각각의 당시 상태를 유지합니다.

예: 첫 상담은 상담중, 다음 통화가 연결되지 않으면 부재, 서류 진행 단계에서는 심사로 기록합니다.

잘못 작성한 내용은 해당 상담 기록의 **수정**을 눌러 고칩니다. 다른 고객을 확인하더라도 작성 중인 상담을 이어 쓸 수 있지만, 프로그램을 닫기 전에는 꼭 저장하세요.

## 4. 견적과 서류 첨부하기

1. 고객을 선택하고 오른쪽 **추가**를 눌러 파일을 고릅니다. 파일을 드래그해서 놓아도 됩니다.
2. 견적, 면허증, 사업자등록증 등 파일 유형을 고릅니다.
3. 견적이라면 **차량 정보, 렌트/리스, 캐피탈**을 지정하고 저장합니다.

사진과 PDF를 첨부할 수 있습니다. 복사한 이미지는 **Ctrl+V**로 붙여넣을 수도 있습니다.

새 견적의 기본 구분은 **렌트**입니다. 캐피탈 이름은 앞부분을 입력해 자동완성으로 선택하고, 없는 항목은 옆의 **+**로 등록합니다. 지점이나 플릿·다이렉트 구분까지 맞는 항목을 골라주세요.

파일을 선택하면 사진을 미리 볼 수 있고, **미리보기 영역을 더블클릭**하면 파일이 열립니다. 파일 정보를 고치려면 오른쪽 **파일 목록의 항목을 더블클릭**합니다.

한 고객이 여러 차종을 비교한다면 견적을 각각 올리고, 각 견적에 실제 차종을 지정하면 됩니다.

## 5. 이전 견적 다시 활용하기

다른 고객에게 사용했던 견적이나 공용 자료가 필요하면 상단 **차량별 자료**를 엽니다.

1. 제조사와 차량명을 선택합니다.
2. 필요하면 유종, 캐피탈, 렌트/리스 조건도 고릅니다.
3. 찾은 자료를 더블클릭해 엽니다.

특정 고객 없이 보관할 견적이나 차량 설명 자료도 이 화면에서 추가할 수 있습니다. 고객 양식의 대표 차량과 각 견적에 지정한 차량은 별도로 관리됩니다.

## 6. 회사 사이트에 상담 내용 옮기기

1. 상담 내용을 저장합니다.
2. 양식 아래 **복사하기**를 누릅니다.
3. 회사 사이트의 입력칸에 **Ctrl+V**로 붙여넣고, 회사 사이트에서도 저장합니다.

복사하기는 양식과 최근 상담 내용을 가져옵니다. 상담 입력칸에 작성 중인 내용이 있으면 그 내용을 우선 사용합니다.

전체 이력이 필요하면 **전체 내보내기**를 사용하세요. 양식과 저장된 모든 상담 기록이 복사되고 TXT 파일도 만들어집니다. 같은 고객명과 전화번호로 다시 내보내면 기존 TXT를 덮어씁니다.

## 7. 상담을 마무리하거나 다시 시작하기

진행이 끝난 고객은 상태를 **인도완료**로 선택해 저장합니다. 더 진행하지 않는 고객은 **폐기**로 정리합니다. 사유를 남기려면 고객 이름 옆의 폐기 버튼을 사용하세요.

인도완료·폐기 고객은 기본 목록에서 빠지고 왼쪽 **폐기 목록**에서 볼 수 있습니다. 기록이 삭제되는 것은 아닙니다. 다시 상담하려면 해당 고객을 선택하고 **복구**를 누르면 상담중으로 돌아옵니다.

부재 상태가 이어질 때는 매일 부재 기록을 남겨도 부재 경과일이 끊기지 않습니다.

## 8. 업무 종료와 데이터 보관

업무를 마치기 전에 작성한 내용을 저장하세요. 상단이 **트레이 켬**이면 창을 닫아도 앱이 실행 중입니다. 완전히 종료하려면 트레이 아이콘을 우클릭하고 종료를 선택합니다.

다른 PC에서 **글 기록만** 이어서 보려면 앱을 완전히 종료한 뒤 실행 파일 옆의 **consultnote.db**를 복사하면 됩니다. 견적과 서류까지 보관하려면 **storage 폴더**도 함께 복사하세요. 첨부파일은 설치 경로가 달라지면 별도의 경로 이전이 필요할 수 있습니다.

다른 PC의 DB를 덮어쓰면 두 기록이 합쳐지는 것이 아니라 가져온 DB로 바뀝니다. 항상 마지막으로 작업한 DB를 사용하고, 덮어쓰기 전 기존 파일을 따로 보관하세요.

새 버전 안내가 나오면 내용을 먼저 저장한 뒤 업데이트합니다. 다운로드가 끝나면 앱이 종료되고 업데이트 후 다시 실행됩니다.

### 평소에는 이 순서만 기억하세요

**고객 선택 → 조건과 상담 내용 작성 → 상태 확인 → 저장 → 필요하면 견적 첨부 또는 회사 사이트에 복사**
