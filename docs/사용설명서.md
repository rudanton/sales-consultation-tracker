# Consult Note 사용 설명서

작성 기준: 2026-10-29 현재 소스 코드. 설치된 배포본이 이전 버전이면 일부 기능이나 버튼이 다를 수 있습니다.

Consult Note는 개인 Windows PC에서 고객 정보, 상담 양식, 상담 기록, 견적서와 서류를 관리하는 프로그램입니다. 회사 사이트에 자동으로 기록을 전송하지는 않습니다. 회사 사이트에 남길 내용은 복사 기능으로 가져와 직접 붙여넣습니다.

## 1. 처음 실행하기

1. 배포용 ZIP을 원하는 폴더에 압축 해제합니다.
2. 폴더 안의 `SalesConsultationTracker.exe`를 실행합니다.
3. 시작 안내 창이 나타나면 데이터 준비가 끝날 때까지 기다립니다.
4. 기존 고객을 선택하거나 새 고객을 추가해 작업합니다.

ZIP 내부에서 바로 실행하지 말고 먼저 압축을 풀어주세요. 일반 배포본은 .NET이 별도로 설치되지 않은 PC에서도 실행할 수 있도록 배포됩니다.

자주 실행하려면 바탕화면이나 작업 표시줄에 바로가기를 두면 됩니다. 바로가기를 사용해도 데이터는 원래 실행 파일이 있는 폴더에서 사용합니다.

### 저장 위치

```text
배포 폴더/
├─ SalesConsultationTracker.exe
├─ 사용법.txt
├─ 사용설명서.md
├─ ConsultNote_사용설명서.pdf
├─ consultnote.db
├─ storage/
│  ├─ customers/
│  └─ vehicle-resources/
├─ backup/
├─ logs/
│  └─ exports/
└─ settings/
```

고객·상담 정보는 `consultnote.db`에, 실제 첨부파일은 `storage`에 저장됩니다. 일부 폴더는 해당 기능을 사용할 때 만들어집니다. 실행 파일만 다른 폴더에 따로 복사하면 그 폴더의 DB를 사용하므로 원래 고객이 사라진 것처럼 보일 수 있습니다.

## 2. 화면 구성

| 위치 | 주로 하는 일 |
|---|---|
| 상단 | 검색, 고객 추가, 차종 목록, 차량별 자료, 트레이 설정, 업데이트 확인 |
| 왼쪽 | 고객 선택, 상태 필터, 정렬, 폐기 목록 조회 |
| 중앙 위쪽 | 이름·연락처·메모 수정, 현재 고객 상태 확인 |
| 중앙 양식 | 렌트/리스 조건, 차량, 초기비용 등 작성 |
| 중앙 상담 기록 | 이번 상담과 상태 작성, 저장, 과거 기록 조회·수정·삭제 |
| 오른쪽 | 고객 파일 추가, 이미지 미리보기, 첨부 목록과 참고 차량 자료 조회 |

오른쪽 영역이 필요 없으면 **사이드바 접기**를 누릅니다. 다시 열려면 **파일 ›**를 누릅니다.

## 3. 고객 등록과 기본 정보

### 새 고객 등록

1. 상단 **고객 추가** 또는 `Ctrl+N`을 누릅니다.
2. 이름을 입력합니다. 이름은 필수입니다.
3. 연락처를 입력합니다. 연락처를 모르면 비워둔 채 등록할 수 있습니다.
4. **저장**을 누릅니다.
5. 등록한 고객을 선택하고 상담 양식과 내용을 작성합니다.

새 고객의 상태는 **상담중**입니다. 연락처는 입력 후 다른 칸으로 이동하면 번호 형식이 정리됩니다.

### 기본 정보 변경과 연락처 복사

중앙의 이름·연락처·메모를 수정한 뒤 상담 기록 영역의 **저장** 또는 `Ctrl+Enter`를 사용합니다. **연락처 복사**는 선택 고객의 전화번호를 클립보드로 가져옵니다. 필요한 곳에서 `Ctrl+V`로 붙여넣습니다.

### 즐겨찾기

고객 이름 옆 **★**를 누르면 즐겨찾기를 켜거나 끕니다. 즐겨찾기 고객은 현재 검색·필터 조건에 해당하는 목록 안에서 먼저 표시됩니다. 폐기 목록 고객이 즐겨찾기라는 이유로 기본 목록에 나타나지는 않습니다.

## 4. 고객 검색과 정렬

### 검색

상단 검색창에 입력하면 고객 목록이 즉시 좁혀집니다. `Ctrl+F`로 검색창에 이동할 수 있습니다.

고객 이름, 전화번호, 차량 정보와 상담 조건 요약을 기준으로 검색합니다. 상담 쓰레드 본문이나 첨부파일의 모든 내용을 검색하는 기능은 아닙니다.

예를 들어 이름 일부, 전화번호 일부, `투싼` 같은 차량명을 입력합니다. 공백으로 여러 단어를 입력하면 각 단어가 모두 맞는 고객을 찾습니다. 각 단어는 서로 다른 검색 대상에 있어도 됩니다.

**초기화**는 검색어를 지우는 버튼입니다. 고객 데이터를 삭제하지 않습니다. 검색어를 지워도 상태 필터나 폐기 목록 선택은 별도로 확인해야 합니다.

### 필터와 정렬

왼쪽 상태 필터에서 전체 또는 특정 상태를 선택합니다. 정렬 기준과 오름·내림 방향도 따로 선택합니다.

| 정렬 기준 | 의미 |
|---|---|
| 등록순 | 프로그램에 고객을 등록한 순서 |
| 최근 상담순 | 마지막 상담 시각 기준 |
| 상태순 | 상담중 → 부재 → 심사 → 계약완료 → 인도완료 → 장기부재 → 폐기 기준 |

즐겨찾기 고객이 우선하므로 전체가 단순한 날짜순으로만 보이지 않을 수 있습니다.

## 5. 상담 조건 양식

고객을 선택한 뒤 양식을 작성합니다. 아직 모르는 정보는 비워둘 수 있습니다.

| 항목 | 작성 방법 |
|---|---|
| 렌트/리스 | 현재 고객이 상담 중인 계약 종류. 개별 견적 파일의 구분과는 별도입니다. |
| 차량스팩 | 제조사 → 차량명 → 유종 순으로 선택하고 상세 칸에 트림·인승·구동 방식·옵션 등을 적습니다. |
| 계약기간 | 단기, 36개월, 48개월, 60개월 중 선택합니다. |
| 주행거리 | 1~5만km 범위의 선택값, 무제한, 직접입력 중 선택합니다. |
| 인도지역 | 지역을 선택하고 상세 지역을 적습니다. |
| 초기비용 | 없음 여부와 선납금·보증금 조건을 적습니다. |
| 명의형태 | 개인, 개인사업자, 법인사업자 중 선택합니다. |
| 사업업력 | 1년 이상이면 토글을 켭니다. |
| 실운전자 | 실제 운전할 사람에 관한 내용을 적습니다. |
| 운전면허 | 취득 1년 이상이면 토글을 켭니다. |
| 보험연령 | 21세·26세·35세·70세 이상 중 선택합니다. |
| 신용상태 | 신용 관련 상담 메모를 적습니다. |
| 특이사항 | 다른 항목에 들어가지 않는 조건이나 참고 사항을 적습니다. |
| 명의자 정보 | 고객과 동일한지 선택하고, 다르면 이름과 연락처를 작성합니다. |

### 주행거리 직접입력

**직접입력**을 선택하면 오른쪽 칸이 열립니다. 만km 단위로 `0~5`, 소수점 한 자리까지 입력합니다. 예를 들어 `1.2`는 12,000km입니다. `12000`을 입력하는 방식이 아닙니다.

다른 항목을 고르면 직접입력 칸이 비활성화되고 직접입력 값은 비워집니다.

### 초기비용 비교

**없음**을 선택해도 선납금과 보증금 값을 함께 작성·저장할 수 있습니다. 초기비용이 없는 조건과 있는 조건을 비교하는 상담에 사용합니다. 선납금과 보증금은 서로 구분해서 보존합니다.

예: 없음 체크 + 선납금 `500만원 조건도 비교` + 보증금 `30% 조건`.

### 토글과 복사 양식

사업업력·운전면허 토글을 켜면 복사 양식에 **1년 이상**, 끄면 빈값으로 표시됩니다. 꺼진 상태를 곧바로 '1년 미만'이라는 확정 정보로 해석하지 않습니다.

양식을 바꾼 뒤에는 **저장** 또는 `Ctrl+Enter`를 사용하세요. **복사하기**는 DB 저장 버튼이 아닙니다.

## 6. 상담 기록 저장과 수정

### 새 기록 작성

1. 고객을 선택합니다.
2. 필요한 기본 정보와 양식을 수정합니다.
3. **상담 기록** 입력칸에 이번 통화 내용을 적습니다.
4. 이번 상담의 **상태**를 고릅니다.
5. **저장** 또는 `Ctrl+Enter`를 누릅니다.

저장하면 기본 정보와 양식이 함께 저장되고, 입력한 상담 내용은 새 기록으로 추가됩니다. 고객의 현재 상태도 선택한 상태로 반영됩니다.

상담 기록마다 당시 상태와 시각을 따로 보관합니다. 오늘 상태를 심사로 저장한다고 과거 부재 기록까지 심사로 바뀌지는 않습니다.

```text
10월 26일  상담중  첫 상담, 차량 조건 확인
10월 27일  부재    오후 통화 시도, 미응답
10월 28일  상담중  재통화, 견적 설명
10월 29일  심사    심사 서류 안내
```

### 저장 버튼의 범위

- 상담 내용이 비어 있으면 빈 상담 기록을 새로 만들지 않습니다. 기본 정보와 양식은 저장합니다.
- 상담 내용이 있으면 기본 정보·양식 저장과 함께 상담 기록을 추가합니다.
- 다음 상담의 상태 기본값은 **상담중**입니다. 저장 후에도 다음 입력을 위해 상담중으로 돌아갑니다.
- 고객 이름 옆의 현재 상태와 다음 상담을 작성할 상태는 서로 다를 수 있습니다.
- 양식만 저장해도 선택한 상태가 고객에게 반영되고 마지막 연락 시도일이 갱신됩니다. 심사 상태를 유지하려면 저장 전에 심사를 선택하세요.

### 작성 중인 내용

앱 실행 중 작성 중인 상담 내용은 고객별 임시 입력으로 보관하는 기능이 있습니다. 다른 고객이나 파일을 확인한 뒤 돌아와 이어 작성할 수 있도록 돕습니다.

이 임시 입력은 DB에 저장된 기록과 다릅니다. 앱 종료·업데이트·PC 종료 전에 반드시 저장하세요. 저장하지 않은 양식 변경도 고객을 바꾸기 전에 저장하는 것이 좋습니다.

### 수정·삭제·부분 복사

과거 기록의 **수정**을 누르면 해당 내용을 입력칸으로 가져옵니다. 내용을 바꾸고 저장하면 그 기록을 수정합니다. 새 기록을 추가하는 상황인지, 기존 기록을 수정하는 상황인지 확인하세요. 수정 저장 시에도 고객의 현재 상태가 선택한 상태로 반영됩니다.

과거 기록의 **삭제**를 누르면 확인 후 해당 기록을 삭제합니다. 화면에서 되돌리는 기능은 없습니다. 저장된 상담 내용은 드래그로 선택하고 `Ctrl+C`로 복사할 수 있습니다.

## 7. 상태와 폐기 목록

| 상태 | 목록 위치 |
|---|---|
| 상담중·부재·심사·계약완료·장기부재 | 기본 고객 목록 |
| 인도완료·폐기 | 폐기 목록 |

**인도완료**로 상담 기록을 저장하면 기본 목록에서 빠지고 폐기 목록에 보입니다. 고객 상태와 상담 기록은 인도완료로 유지됩니다. 폐기 목록은 완료·보관 고객도 함께 조회하는 목록입니다.

### 부재 경과일

부재 상태가 이어지는 동안 다시 부재로 저장해도 시작점을 매번 오늘로 바꾸지 않습니다. 매일 전화해도 받지 않는 경우 부재 기간이 이어집니다. 부재와 장기부재 사이를 바꾸는 경우에도 시작점을 유지합니다.

상담중 등 다른 상태가 되었다가 다시 부재가 되면 새 기간이 시작됩니다. 장기부재를 사용하는 경우 상담 상태 목록에서 선택할 수 있습니다.

### 폐기 사유 남기기

1. 고객을 선택합니다.
2. 고객 이름 옆 **폐기**를 누릅니다.
3. 폐기 사유를 입력하고 확인합니다.
4. 왼쪽 **폐기 목록**을 체크해 해당 고객을 조회합니다.

사유는 폐기 상태 고객의 목록 카드와 상세 정보에서 확인합니다. 상담 기록의 상태를 폐기로 선택해 저장하는 것만으로는 사유 입력창이 열리지 않습니다. 사유를 남기려면 이름 옆 폐기 버튼을 사용하세요.

### 복구

폐기 목록에서 고객을 선택하고 **복구**를 누릅니다. 고객은 상담중으로 돌아오며 기본 고객 목록에 표시됩니다. 폐기 사유는 지워지고 기존 상담 기록은 유지됩니다. 인도완료 고객도 같은 방식으로 복구할 수 있습니다.

## 8. 양식 복사와 전체 내보내기

두 기능 모두 클립보드 복사와 TXT 저장을 함께 수행합니다.

| 버튼 | 포함 내용 | TXT 저장 위치 |
|---|---|---|
| 양식의 **복사하기** | 현재 양식과 상담 내용 한 건 | `logs/exports/날짜시간_고객명.txt` |
| 상담 기록의 **전체 내보내기** | 현재 양식과 저장된 모든 상담 기록 | `storage/customers/고객ID/files/고객명_전화번호뒷4자리_상담기록.txt` |

### 회사 사이트에 붙여넣기

1. 고객과 양식을 확인합니다.
2. **복사하기**를 누릅니다.
3. 회사 사이트의 상담 입력칸을 클릭합니다.
4. `Ctrl+V`로 붙여넣습니다.
5. 회사 사이트에서도 따로 저장합니다.

복사되는 `★상담내용`에는 현재 작성 중인 내용이 있으면 그 내용을 사용합니다. 입력칸이 비어 있으면 가장 최근에 저장한 상담 내용을 사용합니다.

### 전체 이력 내보내기

전체 내보내기는 양식 뒤에 저장된 상담 기록을 과거 → 최신 순서로 붙입니다. 날짜와 당시 상태도 포함합니다.

파일명 예: `홍길동_1234_상담기록.txt`. 같은 고객명·번호로 다시 내보내면 같은 이름의 TXT를 **덮어씁니다**. 이름이나 번호 뒷자리가 바뀌면 파일명도 달라집니다.

현재 입력 중인 내용은 양식 부분에 포함될 수 있지만, 아직 저장하지 않았다면 전체 상담 기록에 새 기록으로 추가되지는 않습니다. 완성된 이력을 보내려면 먼저 저장하고 내보내세요.

## 9. 고객 첨부파일

### 형식과 추가 방법

지원 형식은 `.jpg`, `.jpeg`, `.png`, `.pdf`입니다. Word·Excel·TXT 파일 첨부는 현재 제공하지 않습니다.

1. 오른쪽 **추가**를 눌러 파일을 고릅니다. 탐색기에서 오른쪽 파일 영역으로 드래그해도 됩니다.
2. 파일 유형과 필요한 메타데이터를 입력합니다.
3. **저장**을 누릅니다.

이미지를 클립보드에 복사한 상태라면 앱에서 `Ctrl+V`로 추가할 수도 있습니다. 탐색기에서 PDF 파일 자체를 복사한 것은 이미지 붙여넣기와 다르므로 추가 버튼이나 드래그를 사용하세요.

추가한 파일은 앱 보관 폴더로 복사됩니다. 선택 당시의 외부 원본 파일을 그대로 참조하는 방식은 아닙니다.

### 유형과 순번

명의형태에 따라 면허증, 사업자등록증, 법인 관련 서류 등 선택 목록이 달라집니다. 법인 서류에는 재무제표, 부가세과세표준증명원, 주주명부, 등기부등본, 인감증명서 등을 구분할 수 있습니다.

적절한 항목이 없으면 **기타**를 선택하고 유형명을 입력합니다. 서류 유형 선택이 유효기간이나 적합성을 자동 심사하는 기능은 아닙니다.

견적은 여러 장 추가할 수 있습니다. 순번은 자동 배정됩니다. 견적 메모에 조건 차이를 적어두면 나중에 찾기 쉽습니다.

### 열기·수정·정렬

| 동작 | 결과 |
|---|---|
| 파일 목록 한 번 클릭 | 선택, 이미지이면 상단 미리보기 |
| 파일 목록 더블클릭 | 파일 유형·메모·견적 정보 등 메타데이터 수정 |
| 상단 미리보기 더블클릭 | Windows 기본 연결 프로그램으로 파일 열기 |
| **폴더** | 선택 고객의 파일 보관 폴더 열기 |
| 파일 유형 필터 | 견적이나 특정 서류만 표시 |
| 유형/순서·최신순·파일명순 | 파일 목록 정렬 변경 |

PDF는 사진처럼 페이지를 미리 렌더링하지 않고 PDF 표시가 보일 수 있습니다. 미리보기 영역을 더블클릭해 PDF 프로그램으로 엽니다.

### 삭제할 때

파일을 선택해 **삭제**를 누르고 확인합니다. 보관된 실제 파일을 삭제하며 연결된 차량 자료에도 영향을 줍니다. 차량별 자료와 고객 파일이 같은 파일 경로를 사용하는 경우도 있으므로, 다른 상담에 참고할 견적인지 확인한 뒤 삭제하세요. 단순히 목록에서만 숨기는 기능은 아닙니다.

보관 폴더의 파일을 탐색기에서 임의로 이동·이름 변경하면 앱에 저장된 경로와 달라져 열리지 않을 수 있습니다.

## 10. 견적 구분과 캐피탈 선택

1. 견적을 추가하면서 제조사, 차량명, 유종을 지정합니다.
2. **렌트/리스**를 선택합니다. 새 견적 기본값은 **렌트**입니다.
3. **캐피탈/렌트사**를 고릅니다.
4. 메모에 트림, 연식, 기간, 선납·보증 등 필요한 조건을 적습니다.
5. 저장합니다.

견적의 차종은 고객 양식의 차종과 별도로 지정할 수 있습니다. 한 고객이 투싼과 쏘렌토를 비교한다면 각 견적에 해당 차종을 지정합니다. 고객 양식을 바꾼다고 이전 견적의 차종까지 일괄 변경되지는 않습니다.

### 이름을 타이핑해 선택하기

캐피탈 이름 앞부분을 입력하면 일치하는 등록 항목이 자동완성·선택됩니다. 예를 들어 `현대캐`를 입력한 뒤 원하는 현대캐피탈 항목을 고릅니다. 이름 중간의 글자가 포함된 모든 항목을 찾는 검색과는 다릅니다.

현대캐피탈, 현대캐피탈(플릿), 현대캐피탈(3S)처럼 채널이 나뉘어 있으면 정확한 항목을 선택하세요. 직접 입력해도 등록된 이름과 일치해야 저장됩니다.

### 새 캐피탈 등록

1. 입력칸 옆 **+**를 누릅니다.
2. 이름을 입력하고 **등록**을 누릅니다. 새 이름 입력칸에서는 Enter로도 등록할 수 있습니다.
3. 등록된 항목을 확인하고 견적을 저장합니다.

기존 이름을 약칭으로 다시 추가하지 않도록 먼저 확인하세요. 지점·플릿·다이렉트 등 업무상 구분하는 항목은 별도로 등록할 수 있습니다.

기존 견적 수정 시에는 저장된 렌트/리스를 유지합니다. 과거 구분이 없는 견적은 **미지정**으로 조회되며, 수정 시 필요한 구분을 선택해 저장합니다.

현재 견적 구분 선택지는 렌트·리스입니다. 렌트사 목록에 할부가 있어도 별도의 할부 구분 기능이 구현된 것은 아닙니다.

## 11. 차량별 자료

차종 기준으로 재활용할 견적서·차량설명·홍보자료 등을 보관하고 찾는 화면입니다. 고객에게 연결된 견적과 고객 없이 등록한 공용 자료를 함께 다룰 수 있습니다.

### 공용 자료 추가

1. 상단 **차량별 자료**를 누릅니다.
2. **추가**를 누르거나 파일을 창 안으로 드래그합니다. 클립보드 이미지는 해당 창에서 `Ctrl+V`로 추가할 수 있습니다.
3. 차량 정보와 자료 유형을 지정합니다.
4. 견적이면 렌트/리스와 캐피탈을 고르고 저장합니다.

특정 고객이 없어도 등록할 수 있습니다. 차량설명·홍보자료 같은 견적 이외 자료는 렌트/리스 선택을 요구하지 않습니다.

### 검색·열기·수정

제조사, 차량명, 캐피탈/렌트사, 유종, 렌트/리스를 조합해 필터링합니다. **초기화**는 모든 필터를 전체로 되돌립니다.

예: 현대 → 투싼 → 하이브리드 → 리스 → 원하는 캐피탈. 자료가 없으면 일부 조건을 전체로 바꾸어 확인하세요. 미지정은 과거에 렌트/리스를 기록하지 않은 견적을 찾을 때 사용합니다.

자료를 선택하고 **수정**으로 정보를 변경합니다. **자료 목록을 더블클릭하면 파일이 열립니다.** 고객 파일 목록의 더블클릭과 동작이 다릅니다.

### 다른 고객 견적 참고

A 고객의 쏘렌토 견적을 B 고객에게 참고하려면 상단 차량별 자료에서 쏘렌토로 필터링해 찾습니다. 고객 양식 아래 **차량별 자료** 버튼으로 선택 차종에 대한 참고 검색을 시작할 수도 있습니다. 오른쪽 아래 참고 자료 목록도 더블클릭해 열 수 있습니다.

자료를 열었다고 B 고객의 양식이나 첨부파일이 자동으로 바뀌지는 않습니다. 양식에는 대표 상담 조건을 적고, 비교하는 여러 차량의 조건은 개별 견적과 상담 기록에 구분해 남기면 됩니다.

## 12. 차종 목록

**차종 목록**은 제조사·차량명·유종을 관리하는 화면입니다. 견적 파일을 보관하는 차량별 자료와 구분하세요.

1. 상단 **차종 목록**을 누릅니다.
2. **신규**를 누릅니다.
3. 제조사, 차량명, 유종과 메모를 입력합니다. 차량명은 필수입니다.
4. **저장**을 누릅니다.

유종이 여러 개면 쉼표로 구분합니다. 예: `가솔린, 하이브리드`.

기존 차종은 선택해 수정하고 저장합니다. 비활성화하면 새 입력용 선택 목록에서 숨길 수 있습니다. 과거 고객 기록을 삭제하는 기능은 아닙니다.

제조사 선택은 현대 → 기아 → 제네시스 → KGM → 쉐보레 → 르노를 우선하고 추가 제조사는 이름순입니다. 유종은 가솔린 → 하이브리드 → LPG → 디젤 → 전기 순을 기본으로 사용합니다.

## 13. 상단 업무 집계

프로그램에 **저장한 기록**을 기준으로 계산합니다. 실제 전화 발신이나 회사 사이트 실적을 자동 수집하는 기능이 아닙니다.

| 항목 | 계산 기준 |
|---|---|
| 활성 | 폐기·인도완료를 제외한 고객 수 |
| 최근 7일 상담 | 오늘을 포함해 7일 전 날짜 이후에 마지막 상담 기록이 있는 고객 수 |
| 금주 견적 | 고객 파일에 등록한 견적 파일 수. 여러 장이면 각각 집계 |
| 금주 재접촉 | 고객별 첫 상담 기록을 제외한 이번 주 후속 상담 기록 수 |
| 금주 심사 | 이번 주 심사 상태의 기록이 하나라도 있는 고객 수. 같은 고객은 한 명으로 집계 |

이번 주는 **월요일부터** 계산합니다. 금주 견적·재접촉·심사는 현재 폐기 고객을 제외하며 인도완료 고객은 포함합니다. 고객 없이 차량별 자료에만 올린 공용 견적은 금주 견적에 포함되지 않습니다.

부재 기록도 후속 기록이면 재접촉으로 집계될 수 있습니다. 심사는 실제 외부 접수를 확인한 값이 아니라 저장한 상태 기준입니다. 보고서에 옮길 때 파일 수·기록 수·인원수 중 어떤 단위인지 확인하세요. 기록 수정·삭제에 따라 집계도 달라질 수 있습니다.

## 14. 트레이와 종료

상단 **트레이 끔 / 트레이 켬**으로 X 버튼의 동작을 선택합니다. 기본은 트레이 끔입니다.

| 설정 | X를 눌렀을 때 |
|---|---|
| 트레이 끔 | 앱 종료 |
| 트레이 켬 | 창을 숨기고 Windows 알림 영역으로 이동 |

트레이 아이콘 더블클릭 또는 우클릭 → **열기**로 복구합니다. 실행 파일이나 바로가기를 다시 실행해도 기존 창을 복구합니다.

완전히 종료하려면 트레이 아이콘 우클릭 → **종료**를 선택합니다. 아이콘이 안 보이면 작업 표시줄의 숨겨진 아이콘 영역도 확인하세요.

## 15. 업데이트

일반 배포 실행 파일은 시작 후 새 버전을 확인합니다. 상단 **업데이트 확인**으로 수동 확인도 할 수 있습니다. 인터넷 연결이 필요합니다.

1. 작성 중인 내용을 먼저 저장합니다.
2. 새 버전 안내에서 현재 버전과 최신 버전을 확인합니다.
3. **예**를 누르면 앱이 ZIP을 다운로드합니다.
4. 준비가 끝나면 앱이 종료됩니다.
5. 업데이트 도우미가 프로그램 파일을 교체하고 다시 실행합니다.

아니요를 누르면 현재 버전으로 계속 사용합니다. 업데이트는 DB, storage, backup, logs, settings를 보존하도록 되어 있습니다. 미저장 입력은 DB 데이터와 다르므로 먼저 저장하세요.

개발 실행인 `dotnet run`은 일반 배포본과 시작 시 업데이트 동작이 다를 수 있습니다. 일상 업무 안내는 배포본 기준입니다.

## 16. 백업과 다른 PC로 이동

### 글 기록만 이어서 보기

고객 정보, 상담 양식·기록, 캐피탈 목록 등 DB 내용만 필요하면 **consultnote.db**를 옮깁니다.

1. 원래 PC에서 저장하고 앱을 완전히 종료합니다. 트레이 숨김도 종료는 아닙니다.
2. 실행 파일 옆의 DB를 복사합니다.
3. 대상 PC의 앱도 종료합니다.
4. 대상 PC에 기존 DB가 있으면 먼저 다른 폴더나 이름으로 백업합니다.
5. 가져온 DB를 대상 실행 파일 옆에 놓고 실행합니다.

덮어쓰기는 두 PC의 기록을 합치는 기능이 아닙니다. 가져온 DB로 교체됩니다. 집에서 작업한 뒤 다시 가져올 때도 마지막으로 작업한 DB를 사용하세요. 두 PC에서 각각 작성한 기록이 자동으로 합쳐지지는 않습니다.

### 첨부파일까지 보관하기

DB와 **storage 전체**를 함께 보관합니다. 설정은 settings, 보조 내보내기 TXT는 logs/exports에 있으므로 필요한 경우 포함합니다. 실행 폴더 전체를 별도 복사해 보관하는 방법도 있습니다.

현재 파일 경로는 DB에 **절대 경로**로 저장됩니다. PC 사용자 이름이나 설치 폴더가 달라지면 DB와 storage를 함께 복사해도 예전 경로를 찾지 못할 수 있습니다. 첨부파일까지 이어보려면 같은 전체 폴더 경로를 유지하거나 별도의 경로 이전 작업이 필요합니다.

글 기록만 보는 데에는 첨부파일 경로 차이가 영향을 주지 않습니다. 목록에 파일명이 보여도 실제 파일이 있어야 열 수 있습니다.

### 백업 시 주의할 점

backup 폴더가 있다고 정기 자동 백업이 수행되는 것은 아닙니다. 중요한 작업 전후에 직접 보관하세요.

앱을 완전히 종료한 뒤 DB를 복사합니다. 실행 중 DB 옆에 `consultnote.db-wal`, `consultnote.db-shm`이 있으면 본체만 복사해서 최신 변경을 모두 가져왔다고 보장할 수 없습니다. 보조 파일을 임의로 지우지 말고 앱 종료 여부부터 확인하세요.

## 17. 단축키

| 단축키 | 동작 |
|---|---|
| 메인 `Ctrl+N` | 고객 추가 |
| 메인 `Ctrl+F` | 검색창 이동, 검색어 선택 |
| 메인 `Ctrl+Enter` | 기본 정보·양식·상태·상담 내용 저장 |
| 상담 입력 중 `Tab` → `Enter` | 저장 버튼으로 이동 후 실행 |
| 메인 `Ctrl+V` | 클립보드 이미지가 있으면 고객 파일 추가 |
| 차량별 자료 창 `Ctrl+V` | 클립보드 이미지로 자료 추가 |
| 고객 추가·고객 파일·차량 자료 추가 창 `Ctrl+Enter` | 해당 창의 입력 내용 저장 |
| 차종 목록 창 `Ctrl+Enter` | 편집 중인 차종 저장 |
| 선택 텍스트 `Ctrl+C` | 복사 |

클립보드에 이미지가 있으면 메인 화면의 Ctrl+V는 이미지 첨부로 처리됩니다. 텍스트를 붙여넣으려면 클립보드 내용을 확인하세요.

## 18. 문제 해결

### 저장 후 상태 입력이 상담중으로 바뀌었어요.

다음 상담의 기본값입니다. 저장된 기록과 고객 이름 옆의 현재 상태를 확인하세요. 이전 기록까지 상담중으로 바뀐다는 뜻은 아닙니다.

### 고객이 목록에서 사라졌어요.

검색어·상태 필터·폐기 목록을 확인합니다. 폐기·인도완료 고객은 기본 목록에 보이지 않습니다.

### 양식만 저장했는데 현재 상태가 달라졌어요.

저장 버튼은 선택한 상태도 반영합니다. 기본값이 상담중이므로 기존 상태를 유지하려면 저장 전에 그 상태를 선택해야 합니다.

### 복사된 상담 내용이 최신 저장 기록과 달라요.

입력칸에 작성 중인 내용이 있으면 그 내용을 우선 복사합니다. 입력칸을 확인하세요.

### PDF가 미리보기에서 안 보여요.

사진 미리보기와 PDF 열기는 다릅니다. PDF 항목을 선택하고 미리보기 영역을 더블클릭해 기본 프로그램으로 여세요.

### 차종 목록에는 있는데 선택창에 안 보여요.

활성 여부와 제조사·차량명이 맞는지 확인합니다. 여러 유종은 쉼표로 구분합니다. 차종 목록 수정 후에는 창을 닫아 선택 목록을 갱신해보세요.

### 캐피탈을 입력했는데 저장이 안 돼요.

등록된 이름과 일치해야 합니다. 앞부분 자동완성으로 항목을 고르거나 +로 등록하세요. 채널·지점까지 맞는지 확인합니다.

### 다른 PC에서 기록은 보이는데 파일은 안 열려요.

storage도 옮겼는지, DB의 절대 경로가 새 PC에 존재하는지 확인해야 합니다. 글 기록과 실제 파일은 별도로 보관됩니다.

### 업데이트나 저장에서 오류가 나요.

오류 문구와 현재 버전을 확인합니다. 업데이트는 인터넷 연결, 저장은 실행 폴더의 쓰기 가능 여부도 확인하세요. 실행 폴더의 logs에 기록이 남을 수 있습니다. 문제를 전달할 때 발생 순서·현재 버전·오류 화면을 함께 알려주세요.

### 회사 사이트에도 자동으로 저장되나요?

아닙니다. 복사하기·전체 내보내기로 내용을 가져와 직접 붙여넣고 회사 사이트에서도 저장해야 합니다.

## 19. 하루 사용 예시

### 신규 문의

1. 고객 추가로 이름·연락처를 등록합니다.
2. 차량과 상담 조건을 양식에 작성합니다.
3. 상담 내용과 상태를 작성하고 저장합니다.
4. 복사하기로 회사 사이트에 붙여넣고 회사 사이트에서도 저장합니다.
5. 받은 견적에 실제 차종·렌트/리스·캐피탈을 지정해 추가합니다.

### 기존 고객 재접촉

1. 이름·연락처·차량명으로 검색합니다.
2. 과거 상담과 견적을 확인합니다.
3. 이번 연락 결과를 새 기록으로 남깁니다.
4. 미응답이면 부재, 진행되었으면 상담중·심사 등 해당 상태를 골라 저장합니다.

### 여러 차량 비교

1. 양식에는 현재 대표 조건을 정리합니다.
2. 비교할 견적을 각각 올리고 차종을 개별 지정합니다.
3. 상담 기록에 차량별 조건과 고객 반응을 적습니다.
4. 차량별 자료에서 다른 고객에게 사용했던 같은 차종 견적도 참고합니다.

### 인도 완료와 마감

1. 인도 완료 내용을 적고 상태를 인도완료로 저장합니다.
2. 나중에 폐기 목록에서 기록을 다시 확인합니다.
3. 이력 공유가 필요하면 전체 내보내기를 사용합니다.
4. 하루 업무 후에는 미저장 내용과 회사 사이트 기록을 확인합니다.
5. 앱을 완전히 종료하고, 필요하면 DB와 storage를 백업합니다.
